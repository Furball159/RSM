# Remote System Manager (RSM)
Remote System Manager (RSM) is an extension of Windows Server you never thought you needed!
RSM is designed fully from the ground up to be a powerful powershell based Windows Server Assistant, that from the minute you start up, helps you setup and manage your server.
RSM is what Small Business Server and Windows Home Server should have been!
RSM will be available first as a Virtual Harddisk for imaging and then later as an ISO once I can get the ISO to inject into the actual installation properly.
