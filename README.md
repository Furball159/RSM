# Remote System Manager (RSM)
Remote System Manager (RSM) is an extension of Windows Server you never thought you needed!
RSM is designed fully from the ground up to be a powerful powershell based Windows Server Assistant, that from the minute you start up, helps you setup and manage your server.
RSM is what Small Business Server and Windows Home Server should have been!
RSM will be available as an ISO and later as a standalone version to be installed on existing servers.

<h2>What does it do?</h2>
<p>RSM Pro is designed to help simplify the installation and configuration of Windows Server, Active Directory and Microsoft Exchange</p>
<p>RSM Pro will help you setup and manage your Windows Server system as if it was Small Business Server, but with the manual control and modern security of more modern versions of Windows Server</p>
<p>In a time like this, when we are struggling to battle against keeping our infomation private from the cloud or AI, RSM Pro will help make it easier to self host once more</p>
<p>*IMPORTANT NOTE: YES, AI was indeed used during the making of the program, BUT ONLY when patching mistakes that I couldn't work out, like system draw loops or synatx errors that I couldn't understand, all code was made by hand, and only certain parts were patched.</p>

<h2>How Does it Work?</h2>
<p>RSM Pro is made in powershell as a script that handles the tasks of promotion and installation of AD DS, Exchange and Remote Desktop Gateway in a All in Once Box</p>
<p>It Uses all inbuilt commands like Install-WindowsFeature or New-ADUser and Import-GPO to do all of its back of house tasks, everything the program does can be done via the inbuilt GUI and there is nothing that the program can do that the user couldn't!</p>
<p>The program is by design able to work with Roaming Variables to allow users to setup the system how they want, and therfore means that it can be used anywhere and due to its use of only internal windows commands is completly safe to use</p>
<p>NOTE: That whilst the program is designed and tuned to work and preform its desired functions, this is a MOD still and should be tested by the user before using in a real world application, even known everything uses inbuilt commands Microsoft nor Myself will take any responsibility for a bricked instllation.</p>

<h2>Features:</h2>
<p>Remote Desktop Gateway</p>
<p>Exchange Server 2019 CU15</p>
<p>RoamingProfiles Autoconfiguration</p>
<p>RSM Based Roles (Easy to make groups that have preset permissions using the users desired permissions and converting it to actual AD Objects)</p>
<p>Automatic Split Brain DNS, Exchange and Gateway Configuration</p>
